# Community Resource Sharing and Tool Lending System

Group 1 | Web Programming | Phase 2: HTML and CSS

A small web application for a community tool library. Members can borrow tools,
equipment and books, and organisers keep track of what is on the shelf and who has
what. This phase is the front-end prototype only (HTML and CSS). The forms and
buttons do not do anything yet.

## Pages

| Page | What it shows |
|---|---|
| `login.html` | Log in form |
| `register.html` | Registration form |
| `index.html` | Dashboard with item counts and recent borrowings |
| `items.html` | Table of items with a search and category filter |
| `add-item.html` | Form for adding an item |
| `edit-item.html` | Form for editing an item |
| `borrowings.html` | Table of borrowing records |
| `new-borrowing.html` | Form for recording a borrowing |
| `return-item.html` | Form for recording a return |

## How to open it

Download or clone the repository, then open `login.html` (or `index.html`) in a
browser. Use the links at the top of each page to move around.

## Folders

- `css/style.css` - shared styles (layout, navigation, buttons, forms, tables)
- `css/auth.css` - login and register pages
- `css/dashboard.css` - dashboard statistics
